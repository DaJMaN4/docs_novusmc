# 🪨 Początkujące

Dwie kopalnie na start, dla poziomu **0–5**. Tu zdobędziesz pierwsze rzadkie rudy i zrobisz pierwszy ekwipunek.

## Kopalnia

| Rudy | Potwory |
| --- | --- |
| węgiel, miedź, żelazo | Zombie, Ślimak |
| **jadeit** | Nieumarły Górnik, Zmutowany Insekt |
| **bursztyn** | Szkielet Wojownik |
| **iolit** | Szkielet Kusznik |

## Szyb Nowicjuszy

| Rudy | Potwory |
| --- | --- |
| węgiel, miedź, żelazo | Zombie, Ślimak, Zmutowany Insekt |
| **jadeit** | Kamienny Golem |
| **bursztyn** | Salamandra, Lawowa Salamandra |
| **iolit** | Upiór |

## Co z tego zrobisz

| Ruda | U kowala | Ekwipunek |
| --- | --- | --- |
| Jadeit | (używany od razu) | [Jadeitowa zbroja, miecz i kilof](../kowal/zbroje.md) — poziom 2 |
| Surowy Bursztyn | 11 → Sztabka Bursztynu | Bursztynowa zbroja, miecz i kilof — poziom 3 |
| Surowy Iolit | 7 → Sztabka Iolitu | Iolitowa zbroja, miecz i kilof — poziom 4 |

{% hint style="info" %}
Z silniejszych zombie wypada **Zgniła Tkanka Nieumarłych**, a czasem **Serce Zmutowanego Zombie**.
{% endhint %}
