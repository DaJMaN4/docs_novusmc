# 🌌 Biomy

<figure><img src="../../.gitbook/assets/kres/biomy.png" alt="Biomy Kresu"><figcaption><p>Biomy Kresu</p></figcaption></figure>

Środkowa wyspa ze Smokiem Kresu wygląda jak w zwykłym Minecrafcie, ale zewnętrzne wyspy mają **14 nowych biomów** (nazwy w grze są po angielsku):

## Lasy

| Biom | |
| --- | --- |
| **Chorus Forest** | Las refrenu z fioletowymi drzewami pytadendronu i refrenową trawą. |
| **Shadow Forest** | Mroczny, cienisty las ze smoczymi drzewami i cienistymi jagodami. |
| **Umbrella Jungle** | Dżungla z drzewami parasolowymi i galaretnikami. |
| **Blossoming Spires** | Skalne iglice porośnięte kwitnącymi drzewami tenanei. |
| **Foggy Mushroomland** | Mglista kraina olbrzymich, świecących grzybów. |

## Łąki i jeziora

| Biom | |
| --- | --- |
| **Glowing Grasslands** | Świecące łąki z lumekornem. |
| **Flower Islets** | Kwieciste wysepki. |
| **Megalake**, **Megalake Grove** | Ogromne jezioro i gaj nad nim z drzewami lakugrove. |
| **Waterfall Ponds** | Stawy z wodospadami. |

## Pustkowia i góry

| Biom | |
| --- | --- |
| **Crystal Mountains** | Góry z kryształami zorzy. |
| **Ice Starfield** | Pole lodowych gwiazd. |
| **Dust Wastelands** | Pyłowe pustkowia. |
| **Umbra Valley** | Ciemna dolina z łukami z umbralitu. |
