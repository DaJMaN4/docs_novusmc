# 😈 Potwory

<figure><img src="../../.gitbook/assets/kres/enderling.png" alt="Enderek"><figcaption><p>Enderek</p></figcaption></figure>

Na zewnętrznych wyspach Kresu część endermanów zastępują nowe stwory:

| Potwór | Gdzie | |
| --- | --- | --- |
| **Enderek** | wszystkie zewnętrzne wyspy | Najczęstszy stwór Kresu. |
| **Enderman z Wysp Kresu** | małe wyspy, lasy refrenu, kwieciste wysepki, świecące łąki, kryształowe góry, jeziora, dżungla | Odmiana endermana z zewnętrznych wysp. |
| **Cienisty Wędrowiec** | cieniste lasy, Umbra Valley | Mieszkaniec cienistych lasów. |
| **Zjawa Kresu** | wszędzie, najczęściej cieniste lasy i Umbra Valley | Upiór wysp Kresu. |
| **Osiłek Kresu** | wszędzie, najczęściej kryształowe góry, lodowe pola i pyłowe pustkowia | Rzadszy, silny przeciwnik. |
| **Pełzacz Kresu** | wszędzie, najczęściej dżungla parasolowa, kwitnące iglice i pyłowe pustkowia | Rzadszy przeciwnik. |
| **Szlam Pustki** | jeziora, mglista kraina grzybów, cieniste lasy, Umbra Valley, dżungla | Skacze na graczy. |
| **Endermit** | małe wyspy, lasy refrenu, pyłowe pustkowia | Nieszkodliwy — ucieka i się teleportuje. |
| **Wzmocniony Enderek**, **Wzmocniona Zjawa Kresu** | rzadko; enderki najczęściej w kryształowych górach, zjawy w cienistych lasach | Silniejsze odmiany. |
| **Strażnik Kresu** | bardzo rzadko, najczęściej kryształowe góry i lodowe pola | |
| **Rozszarpywacz Kresu** | cieniste lasy, Umbra Valley — bardzo rzadko | Miniboss z paskiem zdrowia. |

Na środkowej wyspie ze smokiem część endermanów to odmiana **Enderman z Kresu**. W budowlach z purpury, np. w miastach Kresu, czekają **Purpurowy Wartownik**, **Splugawiony Obserwator** i **Wypaczony Obserwator**. Bardzo rzadko przez Kres przechodzi też **Burza Kresu**.

## Co spotkasz w którym biomie

Enderki, Zjawy Kresu, Mimikostki, Zjawy, Endoraczki, Kosmaki i Kosmiczne Dorsze żyją na wszystkich zewnętrznych wyspach. Do tego każdy biom ma swoje stwory:

| Biom | Charakterystyczne stwory |
| --- | --- |
| **Small End Islands** (małe wyspy) | Enderman z Wysp Kresu, Endermit, rzadko Krocznik Kresu |
| **Shadow Forest**, **Umbra Valley** | Cienisty Wędrowiec, Zjawa Kresu, Wzmocniona Zjawa Kresu, Szlam Pustki, bardzo rzadko Rozszarpywacz Kresu |
| **Chorus Forest** | Enderman z Wysp Kresu, Endermit, Szlam Kresu, Ślimak Kresu |
| **Umbrella Jungle**, **Blossoming Spires** | Pełzacz Kresu, Szlam Pustki, Upiorna Ryba, Jedwabna Ćma (iglice) |
| **Megalake**, **Megalake Grove**, **Waterfall Ponds** | Szlam Pustki, Szulkrab, Upiorna Ryba, Ślimak Kresu, Ryby Kresu, Kostkomeduzy, Ważki, Szlam Kresu |
| **Foggy Mushroomland** | Szlam Pustki, Upiorna Ryba, Ślimak Kresu, Ważki, Szlam Kresu |
| **Crystal Mountains**, **Ice Starfield** | Osiłek Kresu, Strażnik Kresu, Wzmocniony Enderek, Szulkrab, rzadko Krocznik Kresu |
| **Dust Wastelands** | Osiłek Kresu, Pełzacz Kresu, Endermit, rzadko Krocznik Kresu |
| **Glowing Grasslands**, **Flower Islets** | Enderman z Wysp Kresu, Ślimak Kresu |

{% hint style="info" %}
W Umbra Valley wcześniej nic się nie pojawiało — teraz żyją tam Cieniste Wędrowce, Zjawy Kresu i Szlamy Pustki.
{% endhint %}
