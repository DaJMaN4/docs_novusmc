# 😈 Potwory

<figure><img src="../../.gitbook/assets/kres/enderling.png" alt="Enderek"><figcaption><p>Enderek</p></figcaption></figure>

Na zewnętrznych wyspach Endu część endermanów zastępują nowe stwory:

| Potwór | Gdzie | |
| --- | --- | --- |
| **Enderek** | wszystkie zewnętrzne wyspy | Najczęstszy stwór Endu. |
| **Enderman z Wysp Endu** | małe wyspy, lasy refrenusu, kwieciste wysepki, świecące łąki, kryształowe góry, jeziora, dżungla | Odmiana endermana z zewnętrznych wysp. |
| **Cienisty Wędrowiec** | cieniste lasy, Umbra Valley | Mieszkaniec cienistych lasów. |
| **Zjawa Endu** | wszędzie, najczęściej cieniste lasy i Umbra Valley | Upiór wysp Endu. |
| **Osiłek Endu** | wszędzie, najczęściej kryształowe góry, lodowe pola i pyłowe pustkowia | Rzadszy, silny przeciwnik. |
| **Pełzacz Endu** | wszędzie, najczęściej dżungla parasolowa, kwitnące iglice i pyłowe pustkowia | Rzadszy przeciwnik. |
| **Szlam Pustki** | jeziora, mglista kraina grzybów, cieniste lasy, Umbra Valley, dżungla | Skacze na graczy. |
| **Endermit** | małe wyspy, lasy refrenusu, pyłowe pustkowia | Nieszkodliwy — ucieka i się teleportuje. |
| **Wzmocniony Enderek**, **Wzmocniona Zjawa Endu** | rzadko; enderki najczęściej w kryształowych górach, zjawy w cienistych lasach | Silniejsze odmiany. |
| **Strażnik Endu** | bardzo rzadko, najczęściej kryształowe góry i lodowe pola | |
| **Rozszarpywacz Endu** | cieniste lasy, Umbra Valley — bardzo rzadko | Miniboss z paskiem zdrowia. |

Na środkowej wyspie ze smokiem część endermanów to odmiana **Enderman z Endu**. W budowlach z purpuru, np. w miastach Endu, czekają **Purpurowy Wartownik**, **Splugawiony Obserwator** i **Wypaczony Obserwator**. Bardzo rzadko przez End przechodzi też **Burza Endu**.

## Co spotkasz w którym biomie

Enderki, Zjawy Endu, Mimikostki, Zjawy, Endoraczki, Kosmaki i Kosmiczne Dorsze żyją na wszystkich zewnętrznych wyspach. Do tego każdy biom ma swoje stwory:

| Biom | Charakterystyczne stwory |
| --- | --- |
| **Small End Islands** (małe wyspy) | Enderman z Wysp Endu, Endermit, rzadko Krocznik Endu |
| **Shadow Forest**, **Umbra Valley** | Cienisty Wędrowiec, Zjawa Endu, Wzmocniona Zjawa Endu, Szlam Pustki, bardzo rzadko Rozszarpywacz Endu |
| **Chorus Forest** | Enderman z Wysp Endu, Endermit, Szlam Endu, Ślimak Endu |
| **Umbrella Jungle**, **Blossoming Spires** | Pełzacz Endu, Szlam Pustki, Upiorna Ryba, Jedwabna Ćma (iglice) |
| **Megalake**, **Megalake Grove**, **Waterfall Ponds** | Szlam Pustki, Szulkrab, Upiorna Ryba, Ślimak Endu, Ryby Endu, Kostkomeduzy, Ważki, Szlam Endu |
| **Foggy Mushroomland** | Szlam Pustki, Upiorna Ryba, Ślimak Endu, Ważki, Szlam Endu |
| **Crystal Mountains**, **Ice Starfield** | Osiłek Endu, Strażnik Endu, Wzmocniony Enderek, Szulkrab, rzadko Krocznik Endu |
| **Dust Wastelands** | Osiłek Endu, Pełzacz Endu, Endermit, rzadko Krocznik Endu |
| **Glowing Grasslands**, **Flower Islets** | Enderman z Wysp Endu, Ślimak Endu |

{% hint style="info" %}
W Umbra Valley wcześniej nic się nie pojawiało — teraz żyją tam Cieniste Wędrowce, Zjawy Endu i Szlamy Pustki.
{% endhint %}
