# 😈 Potwory

<figure><img src="../../.gitbook/assets/kres/enderling.png" alt="Enderek"><figcaption><p>Enderek</p></figcaption></figure>

Na zewnętrznych wyspach Kresu część endermanów zastępują nowe stwory:

| Potwór | |
| --- | --- |
| **Enderek** | Najczęstszy stwór Kresu. |
| **Enderman z Wysp Kresu** | Odmiana endermana z zewnętrznych wysp. |
| **Cienisty Wędrowiec** | Mieszkaniec cienistych lasów, spotkasz go też w innych lasach Kresu. |
| **Zjawa Kresu** | Upiór wysp Kresu. |
| **Osiłek Kresu** | Rzadszy, silny przeciwnik. |
| **Pełzacz Kresu** | Rzadszy przeciwnik. |
| **Wzmocniony Enderek**, **Wzmocniona Zjawa Kresu** | Rzadkie, silniejsze odmiany. |
| **Strażnik Kresu** | Bardzo rzadki strażnik. |

Na środkowej wyspie ze smokiem część endermanów to odmiana **Enderman z Kresu**. W budowlach z purpury, np. w miastach Kresu, czekają **Purpurowy Wartownik**, **Splugawiony Obserwator** i **Wypaczony Obserwator**. Bardzo rzadko przez Kres przechodzi też **Burza Kresu**.

## Stworzenia Kresu

<figure><img src="../../.gitbook/assets/kres/zjawa.gif" alt="Zjawa"><figcaption><p>Zjawa</p></figcaption></figure>

Na wyspach Kresu żyją też dziwne stworzenia:

| Stworzenie | Gdzie | |
| --- | --- | --- |
| **Szlam Kresu** | lasy refrenu, mglista kraina grzybów, megajeziora | Kilka odmian szlamu. |
| **Ważka** | mglista kraina grzybów, megajeziora | Latający owad. |
| **Jedwabna Ćma** | kwitnące iglice | |
| **Ryba Kresu**, **Kostkomeduza** | megajeziora, mglista kraina grzybów | Pływają w wodzie. |
| **Mimikostka** | wszystkie zewnętrzne wyspy Kresu | Wrogi sześcian. |
| **Zjawa** | wszystkie zewnętrzne wyspy Kresu | Ogromny, latający duch. |
| **Endoraczek** | wszystkie zewnętrzne wyspy Kresu | Spokojny niesporczak Kresu. |
| **Enderofag** | wszystkie zewnętrzne wyspy Kresu — rzadko | Mały, wirusowy stwór Kresu. |
| **Kosmak** | wszystkie zewnętrzne wyspy Kresu | Latający stwór. Wypada z niego owoc refrenu. |
| **Kosmiczny Dorsz** | środkowa i wszystkie zewnętrzne wyspy Kresu | Ryba, która pływa w powietrzu. Wypada z niej kosmiczny dorsz do zjedzenia. |
