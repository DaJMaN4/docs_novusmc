# 👋 Tryby gry

Na **NovusMC** (adres: **`novusmc.pl`**) możesz grać w trzech trybach. Każdy to osobny świat z własną ekonomią, rangami i postępem — to, co zdobędziesz w jednym trybie, nie przechodzi do innego.

## Który tryb wybrać?

| Lubisz… | Wybierz |
| --- | --- |
| zwiedzać świat, budować i rozwijać postać | **Survival** |
| kopać, walczyć z potworami i zdobywać coraz lepszy ekwipunek | **CaveBlock** |
| rozbudowywać jedną bazę od zera i walczyć o najlepszą wyspę | **Skyblock** |

## Co jest takie samo w każdym trybie

* **`/menu`** — menu główne: regulamin, linki, wiki, sklep i ustawienia.
* **`/pomoc`** — poradnik trybu w grze.
* **`/regulamin`** — ten sam regulamin na wszystkich trybach.
* **Rangi VIP, SVIP i MVIP** oraz **Ogniste Kryształy** — zobacz [Rangi i Ogniste Kryształy](rangi-i-krysztaly.md). Rangę kupujesz osobno w każdym trybie.
* **Skrzynie, Piniata, codzienne nagrody (`/daily`) i osiągnięcia (`/osiagniecia`)**.
