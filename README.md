# 👋 Witaj

Witaj na trybie **CaveBlock** serwera NovusMC! To połączenie klasycznego caveblocka z elementami **RPG**. Dostajesz własną podziemną **jaskinię**, w której budujesz, a surowce zdobywasz w wielkich **kopalniach** pod spawnem — z potworami, bossami i coraz rzadszymi rudami.

{% hint style="info" %}
Większość informacji znajdziesz też w grze — komenda **`/pomoc`** albo **Informacje** w menu głównym (**`/menu`**).
{% endhint %}

## Jak to działa w skrócie

1. **Twoja jaskinia** (**`/cave`**) — prywatne miejsce do budowania. Nie ma w niej surowców.
2. **Kopalnie** na spawnie — tu wykopiesz rudy i walczysz z potworami. Każda kopalnia ma **zalecany poziom**.
3. **Poziom gracza** rośnie, gdy kopiesz, walczysz i farmisz. Wyższy poziom odblokowuje lepszy ekwipunek.
4. **Kowal** przetapia rzadkie rudy na sztabki i robi z nich zbroje, broń i kilofy.
5. **Głębsze jaskinie** strzegą bossowie — pomogą ci zaklęcia, mikstury i runy.
