# ⭐ Rangi

Rangi kupisz za **kryształy** w sklepie premium (**`/sklep`** lub **`/rangi`**). Każda wyższa ranga ma wszystko to, co niższa. Posiadając niższą rangę, wyższą kupisz taniej — o wartość rangi, którą już masz.

* [VIP](vip.md) — **`/vip`**
* [SVIP](svip.md) — **`/svip`**
* [MVIP](mvip.md) — **`/evip`**
