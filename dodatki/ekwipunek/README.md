## Gwiezdny ekwipunek

Ekwipunek z **gwiezdnych kryształów** (zobacz [Gwiezdne odłamki](../maszyny/README.md#gwiezdne-odlamki)). Naprawisz go gwiezdnym kryształem, przyjmuje zaklęcia jak diamentowy.

| Przedmiot | Statystyki |
| --- | --- |
| Gwiezdny miecz | 6 obrażeń, szybkość ataku 2,0 |
| Gwiezdny kilof | kopie bardzo szybko (2× szybciej niż pozostałe gwiezdne narzędzia) |
| Gwiezdny topór | 9 obrażeń |
| Star Shovel, Gwiezdna motyka | szybkie kopanie |
| Hełm / napierśnik / nogawice / buty | 2 / 7 / 6 / 2 pancerza |

Narzędzia mają 250, a zbroja 350 punktów wytrzymałości.
