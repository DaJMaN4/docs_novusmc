# ⌨️ Komendy

## Podstawowe

| Komenda | Opis |
| --- | --- |
| `/menu` | Menu główne: umiejętności, gildie, jaskinia, kity, profil, sklep. |
| `/pomoc` | Poradnik w grze — opis wszystkich mechanik. |
| `/spawn` | Teleport na spawn (wejścia do kopalni, kowal, NPC). |
| `/staty` | Menu umiejętności. |
| `/plecak` | Twój plecak. |
| `/kit` | Zestawy (zależne od rangi). |
| `/daily` | Dzienne nagrody. |
| `/linki` | Discord, sklep i strony do głosowania. |
| `/regulamin` | Regulamin serwera. |

## Jaskinia

| Komenda | Opis |
| --- | --- |
| `/cave` | Teleport do twojej jaskini. |
| `/jaskinia` | Menu jaskini: ulepszenia, ustawienia, biomy, drużyna. |
| `/cave settings` | Ustawienia i uprawnienia w jaskini. |
| `/cave biomes` | Zmiana biomu jaskini. |
| `/cave team` | Drużyna jaskini. |
| `/cave team invite <gracz>` | Zaprasza gracza do drużyny. |
| `/cave team coop <gracz>` | Dodaje gracza do kooperacji (nie traci swojej jaskini). |
| `/cave level` | Przelicza poziom jaskini. |
| `/cave top` | Ranking jaskiń. |
| `/cave warps` | Warpy jaskiń innych graczy. |
| `/cave limits` | Limity bloków i mobów w jaskini. |
| `/cave chat` | Czat jaskini (tylko dla drużyny). |
| `/cave fly` | Latanie w jaskini (MVIP). |

## Handel

## Przydatne

| Komenda | Opis |
| --- | --- |
| `/drop` | Włącza / wyłącza drop prosto do ekwipunku. |
| `/drwal` | Włącza / wyłącza grawitację drzew. |
| `[pos]`, `[ping]` na czacie | Pokazuje innym twoją pozycję albo ping. |
